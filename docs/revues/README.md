# Revues de code

Un rapport par passe complète de revue, nommé par sa date (`AAAA-MM-JJ.md`). Chaque passe repart de
la précédente : ce qui y a été accepté n'est pas re-signalé, ce qui reste ouvert est repris.

La procédure, la grille de lecture, le tri et la forme du rapport sont dans
`.claude/skills/revue-de-code/` ; elle se lit aussi à la main. Les signaux mesurables viennent de
`pnpm proprete`.
